How it works

01

Price the risk

Black-Scholes gives each stock's call option a delta, N(d₁): how many dollars the option gains when the stock rises $1.

02

Encode as qubits

Each stock is one qubit (1 = buy). An XY mixer and a Dicke start state keep exactly k stocks selected. The delta cap becomes a QUBO penalty with a few slack qubits.

03

Run QAOA

COBYLA tunes alternating cost and mixer layers so high-return, feasible portfolios are measured more often. The best valid measurement is the answer.

04

Verify classically

For up to 8 assets an exhaustive search is instant, so every QAOA answer is checked against the true optimum.

Data is illustrative, not live market data, and nothing here is investment advice. The quantum circuit runs on Qiskit Aer, a classical simulator, so it is slower than the exhaustive search at this size. The value is in the formulation, which carries over to quantum hardware.
